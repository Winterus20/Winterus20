## What I work on

**AI infrastructure** — Multi-provider LLM gateways, MCP tool servers, agent orchestration. Most of my infrastructure runs on a single self-hosted VPS: an LLM gateway, a vector-backed memory vault, and a Telegram/Discord bot bridge.

**Minecraft server engineering** — Purpur server operations, custom Java plugins, audio optimization, and player-facing economy design. Tuning JVM flags, reading kernel OOM logs, and automating server maintenance are part of the job, not an afterthought.

**Systems work** — Linux hardening (UFW, fail2ban, geo-restriction, intrusion forensics), Docker services, systemd unit design, and database migrations.
